## Traffic Simulator

The project is made to simulate traffic under different road conditions.The bound of the program will include:
1. road networks
2. Vehicles with variable driving style:
    1. Acceleration
    2. Response time
3. Traffic lights & intersections
4. Pathfinding
5. Randomized destinations


The program will be custamizable and will allow the user to add different number of cars, experiment with different roads

The program will provide analytical data about the simulation such as graphs
